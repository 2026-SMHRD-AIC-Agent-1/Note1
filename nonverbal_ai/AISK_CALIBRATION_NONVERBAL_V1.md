# A!SK 캘리브레이션 및 비언어 평가 기준 V1

확정일: 2026-09-14

## 1. 핵심 원칙

비언어 평가는 개인별 캘리브레이션이 정상적으로 완료된 경우에만 의미가 있다. 따라서 캘리브레이션은 면접 시작 전 **필수 통과 절차(하드 게이트)** 로 운영한다.

- 캘리브레이션 실패 상태에서는 실제 질문으로 넘어가지 않는다.
- 사람마다 다른 카메라 위치, 체형, 평소 자세를 하나의 절대 기준으로 평가하지 않는다.
- 캘리브레이션에서 확보한 개인 기준과 실제 답변 중 변화량을 비교한다.
- 심리 상태, 자신감, 불안감 같은 성향을 비언어 신호만으로 추론하지 않는다.

## 2. 사용자 흐름

`카메라/마이크 권한 -> 1단계 시각 캘리브레이션 -> 2단계 음성 환경 확인 -> 통과 -> 질문 1~3 -> 결과 리포트`

## 3. 캘리브레이션 V1

### 3.1 1단계: 시각 캘리브레이션

- 화면 중앙 표시점을 바라본다.
- 얼굴 전체, 양쪽 눈, 양쪽 어깨가 모두 화면 안에 들어와야 한다.
- 기준 상태를 **3초 연속** 유지해야 통과한다.
- 중간에 프레임 기준에서 벗어나면 3초 카운트를 다시 시작한다.
- 실시간 상태 안내를 제공한다.
- 저장 기준: 정면 시선, 고개 방향, 어깨 각도, 상체 위치/크기.

### 3.2 2단계: 음성 환경 확인

고정 문장:

> 안녕하세요. 지금부터 면접을 시작하겠습니다.

목적은 말하기 능력 평가가 아니라 **분석 가능한 녹음 환경 확인**이다.

- 마이크 입력 정상 여부
- 주변 소음 수준
- 목소리 측정 가능 여부
- 기본 음량은 개인 기준값으로 저장하되 점수에 직접 반영하지 않는다.
- 읽기 속도, 피치, 말투는 캘리브레이션 점수 기준으로 사용하지 않는다.

### 3.3 실패 처리

- 자동 포기/소프트 통과 없음.
- 통과할 때까지 재시도한다.
- 카메라/마이크 자체 문제이면 환경을 확인한 뒤 다시 시도하도록 안내한다.

## 4. 비언어 평가 V1

### 4.1 시선 안정성

- 개인 기준: 캘리브레이션 시 화면 중앙 응시.
- 의미 있는 시선 이탈: **1초 이상 지속**.
- 평가값: 이탈 횟수 + 전체 답변 중 이탈 시간 비율.
- 질문별로 계산하고, 세션 전체는 3개 질문 평균으로 요약한다.
- 캘리브레이션이 성공한 iris 기반 시선만 점수 후보로 사용한다.

### 4.2 자세 안정성

- 개인 기준: 캘리브레이션 시 안정 자세.
- 의미 있는 자세 이탈: **2초 이상 지속**.
- 함께 보는 신호: 고개 방향 + 어깨 기울기 + 상체 위치.
- 평가값: 이탈 횟수 + 전체 답변 중 이탈 시간 비율.
- 질문별로 계산하고, 세션 전체는 3개 질문 평균으로 요약한다.

### 4.3 면접 중 재캘리브레이션

- 짧은 면접이므로 중간 재캘리브레이션은 하지 않는다.
- 사용자가 자세/시선을 크게 바꾸면 그 변화 자체를 평가에 반영한다.
- 카메라 끊김/프레임 오류는 사용자 행동이 아니라 기술 오류/측정 불가로 처리한다.
- 영상은 정상인데 사용자가 스스로 화면 밖으로 벗어나면 행동 이탈로 기록한다.

## 5. 말하기 습관 리포트

사용자 화면에서 `필러`라는 용어는 사용하지 않는다.

### 머뭇거림 표현

- 명확한 표현: `어`, `음`, `저기`, `뭐랄까` 등.
- 문맥형 표현: `그`, `약간` 등은 실제 머뭇거림이 확실한 경우에만 리포트에 포함한다.
- 표현별 횟수와 발생 시점을 보여준다.

### 반복 표현

- `제가 제가`, `먼저 먼저`처럼 같은 표현을 연속 반복한 경우 별도 표시한다.
- 횟수와 발생 시점을 보여준다.

### 점수 정책

- 머뭇거림 표현: **점수 제외, 코칭 리포트 전용**.
- 반복 표현: **점수 제외, 코칭 리포트 전용**.

## 6. 아직 미확정인 항목

- 전달 안정성 100점의 항목별 최종 가중치
- 각 지표의 점수 환산 구간/threshold
- 발화 속도의 최종 primary metric

## 7. 코드 반영 위치

- `calibration_policy_v1.py`: 팀 합의 정책 상수/계약
- `calibrate_from_webcam.py`: 2단계 하드 게이트 캘리브레이션 로컬 구현
- `runtime_patches.py`: 시선 1초, 자세 2초 지속 기준
- `stability_features.py`: 캘리브레이션 완료 시 시선/자세 점수 후보 활성화
- `delivery_stability_v1.py`: 결과 리포트용 구조
- `핵심프로젝트 코드/backend/stt_stability_features.py`: 머뭇거림/반복 표현 횟수와 발생 시점

## 8. 프론트엔드 연결 시 필요한 UI

- 중앙 표시점
- 3초 연속 안정 유지 카운트
- 얼굴/눈/어깨 상태 안내
- 고정 문장 표시 및 마이크/소음 상태 안내
- 캘리브레이션 성공 전 면접 시작 비활성화
- 결과 리포트에서 질문별 시선/자세와 말하기 습관 발생 시점 표시
