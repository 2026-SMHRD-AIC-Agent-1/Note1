            "pitch_variation": ..., "filler_word_count": ...,
            "voice_emotion_label": None,  # 항상 None. 평가 제외 항목이라 값 생성 안 함.
        }

    [주의]
        - 애매한 매핑은 DB_FIELD_MAPPING_NOTES에 이유를 적어뒀음. 팀 합의로 바뀌면 여기만 수정.
        - head_nod_count는 nod_count와 shake_count를 합산함 -> 방향 구분이 사라짐.
          shake_count가 0이 아니면 경고를 출력해서, 젓기 동작이 있었다는 걸 놓치지 않게 함.
        - voice_emotion_label은 측정기준정의서상 "평가 제외" 항목이므로 값을 만들지 않고
          항상 None으로 둠. 화면/코칭에 노출하지 말 것.
    """
    nod = result.get("nod_count", 0)
    shake = result.get("shake_count", 0)
    if shake > 0:
        print(f"[경고] shake_count={shake}로 감지됐지만 head_nod_count 필드 하나에 합쳐집니다. "
              f"고개를 저은 정보가 DB에서 구분되지 않습니다 - Backend와 필드 분리 여부 확인 필요.")

    return {
        "face_yaw": result.get("face_yaw"),
        "gaze_center_ratio": result.get("gaze_center_ratio"),
        "blink_rate": result.get("blink_per_min"),
        "smile_intensity": result.get("smile_avg_intensity"),
        "expression_change_count": result.get("expression_change_count"),
        "upper_body_sway": result.get("body_movement_score"),
        "head_nod_count": nod + shake,
        "hand_gesture_rate": result.get("gesture_per_min"),
        "pause_count": result.get("pause_count"),
        "average_volume": result.get("mean_db"),
        "speaking_speed": result.get("speaking_speed"),
        "pitch_variation": result.get("f0_std"),
        "filler_word_count": result.get("filler_word_count"),
        "voice_emotion_label": None,  # 평가 제외 - 값 생성하지 않음
    }
