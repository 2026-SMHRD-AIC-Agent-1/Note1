# 연진 비언어 AI 파트

연진이 전달한 비언어 분석 원본을 보존하면서, 45개 파일럿 검토에서 확인된 계산 오류와 안정성 평가용 전처리를 분리해 관리합니다.

## 파일
- `calibrate_from_webcam.py`: 웹캠/마이크 캘리브레이션 코드
- `nonverbal_analysis_v3.py`: 원본 실행 래퍼. 원본을 복원한 뒤 `runtime_patches.py`의 검증된 수정사항을 적용
- `_source_parts/nonverbal_analysis_v3.part01.txt` ~ `part07.txt`: 연진이 전달한 `nonverbal_analysis_v3.py` 원문 조각
- `runtime_patches.py`: 45개 파일럿 검토에서 확인된 계산 오류 수정
- `stability_features.py`: 원시 비언어 결과를 안정성 평가용 정규화 지표와 측정상태로 변환
- `delivery_stability_v1.py`: STT 안정성 feature + 비언어 feature를 리포트/점수 입력 구조로 합침. 최종 가중치·임계값은 아직 넣지 않음
- `run_nonverbal_batch.py`: 영상→WAV→기존 STT 연결→비언어 분석→delivery profile까지 한 번에 생성

원본 분석 파일이 커서 업로드 과정에서 잘리지 않도록 조각으로 보존했고, `nonverbal_analysis_v3.py`가 실행 시 조각을 순서대로 결합합니다.

## 2026-09-14 45개 파일럿 검토 반영

전체 45개 영상에서 통합 배치가 성공했고, 오디오 측정불가 4개(무음 계열)를 `measurement_unavailable`로 분리했습니다.

명확한 계산/품질 문제는 먼저 수정하되, 평가 임계값은 임의로 고정하지 않습니다.

1. 홍채 기반 시선에서 눈 감음/아래보기 등 측정 불가 프레임을 `정면`으로 계산하지 않고 비율 분모에서 제외합니다. `gaze_valid_frame_ratio`를 추가했습니다.
2. 필러워드 fallback 계산에서 `그`를 `그리고` 안에서 세는 식의 부분문자열 오탐을 막고 독립 토큰만 셉니다.
3. 발화속도용 문자 수 계산에서 공백뿐 아니라 쉼표·마침표 등 구두점을 제외합니다.
4. 45개 파일럿이 모두 `calibration_used=False`였으므로, **캘리브레이션된 iris만 향후 시선 점수 후보**로 허용합니다. 캘리브레이션 없는 iris와 `head_pose_approx`는 참고값입니다.
5. 얼굴/상체 이탈은 파일럿에서 희소하게 검출되어 현재 점수에서 제외하고 참고값으로 유지합니다.
6. 오디오가 무음/품질불가이면 STT가 그럴듯한 문장을 환각할 수 있으므로, raw STT는 감사용으로 보존하되 `language_analysis_allowed=False`로 표시해 언어/전달 점수 입력을 막습니다.
7. STT와 비언어를 `delivery_profile_v1`로 합쳐, 실제 리포트/점수 단계에서 사용할 수 있는 입력 구조를 만들었습니다.

## 현재 안정성 평가 원칙

- **말하기 흐름**: 실제 오디오 신호의 pause를 주 측정으로 사용. Whisper word gap은 보조값
- **속도 안정성**: 휴지 제외 articulation rate와 휴지 포함 speech rate를 둘 다 보존. 어떤 값을 최종 점수의 대표 속도로 쓸지는 제품 결정 필요
- **음량 안정성**: 사람 간 평균 dB가 아니라 답변 내부 변동폭(`db_std`)을 점수 후보로 사용
- **필러/반복**: 강한 필러와 문맥 필러를 분리. 현재 파일럿에서 Whisper가 강한 필러를 거의 보존하지 않아 우선 리포트/코칭용
- **시선**: 캘리브레이션된 `iris`만 향후 점수 후보. 나머지는 참고값
- **고개/자세**: 기준점 대비 이탈 지표는 보존하되 추가 검증 전까지 참고값
- **눈깜빡임·미소·표정변화·끄덕임·젓기·제스처·피치**: 설명/참고 정보
- **측정 실패**: 0점이 아니라 `measurement_unavailable`; 필요 시 재녹화 권고
- 성격·자신감·진정성·불안 같은 심리 특성은 추론하지 않음

## 최종 점수 전에 남은 제품 결정

1. 안정성 100점의 가중치/정규화 방식을 어떻게 할지
2. 속도 점수의 대표값을 `articulation rate(휴지 제외)`로 할지 `speech rate(휴지 포함)`로 할지
3. flow/pace/volume의 실제 점수 구간(임계값)을 어떤 근거로 정할지
4. 캘리브레이션된 시선을 V1 점수에 바로 넣을지, V1에서는 리포트만 하고 V2에서 점수화할지

이 결정 전까지 코드는 raw measurement, 측정상태, 리포트용 통합 profile까지만 확정하고 최종 0~100 점수는 생성하지 않습니다.
