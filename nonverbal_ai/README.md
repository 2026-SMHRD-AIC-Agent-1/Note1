## 2026-09-14 45개 파일럿 검토 반영

전체 45개 영상에서 통합 배치가 성공했고, 오디오 측정불가 4개(무음 계열)를 `measurement_unavailable`로 분리했습니다.

명확한 계산/품질 문제는 먼저 수정하되, 최종 점수 가중치·구간은 임의로 고정하지 않습니다.

1. 홍채 기반 시선에서 눈 감음/아래보기 등 측정 불가 프레임을 `정면`으로 계산하지 않고 비율 분모에서 제외합니다. `gaze_valid_frame_ratio`를 추가했습니다.
2. 필러 fallback 계산에서 `그`를 `그리고` 안에서 세는 식의 부분문자열 오탐을 막고 독립 토큰만 셉니다.
3. 발화속도용 문자 수 계산에서 공백뿐 아니라 쉼표·마침표 등 구두점을 제외합니다.
4. 45개 파일럿이 모두 `calibration_used=False`였으므로, **캘리브레이션 없는 시선/자세 결과는 점수에 사용하지 않습니다.**
5. 오디오가 무음/품질불가이면 STT가 그럴듯한 문장을 환각할 수 있으므로, raw STT는 감사용으로 보존하되 `language_analysis_allowed=False`로 표시해 언어/전달 점수 입력을 막습니다.
6. STT와 비언어를 `delivery_profile_v1`로 합쳐 실제 리포트/점수 단계에서 사용할 수 있는 입력 구조를 만들었습니다.

## A!SK 캘리브레이션 V1 — 확정

캘리브레이션은 선택 기능이 아니라 **면접 시작 전 필수 통과 절차(하드 게이트)** 입니다.

### 1단계 시각 캘리브레이션
- 화면 중앙 표시점을 응시
- 얼굴 전체 + 양쪽 눈 + 양쪽 어깨가 화면 안에 위치
- 기준 상태 **3초 연속 유지**
- 중간 이탈 시 3초 카운트 재시작
- 시선/고개/어깨/상체 개인 기준값 저장

### 2단계 음성 환경 확인
고정 문장: `안녕하세요. 지금부터 면접을 시작하겠습니다.`

- 목적은 말하기 능력 평가가 아니라 마이크/소음/음성 측정 가능 여부 확인
- 기본 음량은 개인 기준으로 저장하되 점수에 직접 넣지 않음
- 읽기 속도, 피치, 말투는 캘리브레이션 점수 기준에서 제외
- 통과하지 못하면 질문으로 넘어가지 않고 재시도

## 현재 안정성 평가 원칙

- **시선 안정성**: 캘리브레이션된 iris만 점수 후보. 의미 있는 이탈은 1초 이상 지속. `이탈 횟수 + 이탈 시간 비율`을 함께 사용
- **자세 안정성**: 캘리브레이션 완료 시 점수 후보. 고개 방향 + 어깨 기울기 + 상체 위치를 함께 보고, 의미 있는 이탈은 2초 이상 지속. `이탈 횟수 + 이탈 시간 비율`을 함께 사용
- **질문별 평가**: 시선/자세는 질문별로 계산하고 세션 전체는 3개 질문 평균으로 요약
- **중간 재캘리브레이션 없음**: 짧은 면접에서 사용자가 자세/시선을 크게 바꾸면 그 변화 자체를 평가에 반영
- **기술 오류 분리**: 카메라/프레임 오류는 사용자 행동과 분리해 측정 불가로 처리. 영상은 정상인데 사용자가 화면 밖으로 벗어나면 행동 이탈
- **말하기 흐름**: 실제 오디오 신호의 pause를 주 측정으로 사용. Whisper word gap은 보조값
- **속도 안정성**: 휴지 제외 articulation rate와 휴지 포함 speech rate를 둘 다 보존. 어떤 값을 최종 점수의 대표 속도로 쓸지는 제품 결정 필요
- **음량 안정성**: 사람 간 평균 dB가 아니라 답변 내부 변동폭(`db_std`)을 점수 후보로 사용. 캘리브레이션 기본 음량은 리포트 보조 기준
- **머뭇거림 표현/반복 표현**: 사용자 리포트 전용, 점수 제외. 표현별 횟수와 발생 시점을 제공
- **눈깜빡임·미소·표정변화·끄덕임·젓기·제스처·피치**: 설명/참고 정보
- **측정 실패**: 0점이 아니라 `measurement_unavailable`
- 성격·자신감·진정성·불안 같은 심리 특성은 추론하지 않음

## 최종 점수 전에 남은 제품 결정

1. 안정성 100점의 항목별 가중치/정규화 방식
2. 속도 점수의 대표값을 `articulation rate(휴지 제외)`로 할지 `speech rate(휴지 포함)`로 할지
3. flow/pace/volume/calibrated gaze/calibrated posture의 실제 점수 구간(임계값)

이 결정 전까지 코드는 raw measurement, 측정상태, 리포트용 통합 profile까지 확정하고 최종 0~100 점수는 생성하지 않습니다.
