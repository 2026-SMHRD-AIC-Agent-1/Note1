# AI 모의면접 팀 프로젝트 통합 현황

기준일: 2026-09-15

## 프로젝트 완성 기준

이번 프로젝트의 목표는 외부 클라우드 서버 배포가 아니라 **한 대의 PC에서 실제 기능이 처음부터 끝까지 동작하고, 그 과정을 영상으로 촬영해 제출·발표할 수 있는 로컬 데모 완성**이다.

공통 목표 흐름:

`동의 → 기업/직무 선택 → 캘리브레이션 → 질문 생성 → 답변 녹화 → STT → 내용평가 + 전달분석 → 최종 리포트`

면접 유형별 질문 흐름:

- **A!SK**: `직무이해 → 문제해결 → 협업 → 종료`
- **심층면접**: `첫 질문 → 답변 기반 꼬리질문 1 → 꼬리질문 2 → 꼬리질문 3 → 종료`
  - 꼬리질문은 한 번에 1개씩 생성
  - 직전 답변 STT를 보고 다음 질문 생성
  - 최대 3회
  - 같은 세션 안에서 이어지는 꼬리질문과, 다음 회차 연습 질문은 서로 다른 기능

## 현재 연결된 부분

### 1. 내용평가 흐름
- 기업/직무 선택
- 면접 세션 생성
- A!SK 질문 3개 생성
- 심층면접 첫 질문 1개 생성
- 심층면접 답변 기반 꼬리질문 최대 3회 생성 및 프론트 진행 흐름 연결
- 답변 영상/음성 녹화 및 업로드
- 기본 STT
- RAG/언어 AI 답변 분석
- 직무 핵심 반영도 / 답변 구성 충실도
- 세션 내용 종합 코칭

심층면접 꼬리질문은 현재 실제 웹 런타임에서도 최상위 RAG 통합 규격과 같은 형식을 사용한다.
각 꼬리질문마다 다음 값이 함께 생성된다.
- `question_text`
- `question_reason`
- `evaluation_points` 3개
- `rag_evidence`
- `practice_reason`

이를 위해 `backend/rag_ai/deep_followup_contract.py`를 추가했고, 실제 FastAPI 심층면접 API가 이 통합 형식을 사용한다.

### 2. 상세 STT / 말하기 습관
답변 제출 시 기본 STT와 별도로 상세 STT를 실행한다.

현재 계산·표시:
- 머뭇거림 표현: 사용자 리포트 전용, 점수 제외
- 반복 표현: 사용자 리포트 전용, 점수 제외
- 표현별 횟수
- 발생 시점
- 발화 속도 관련 raw feature
- Whisper word-gap은 침묵의 보조값으로만 사용

머뭇거림/반복 발생 시점은 `NONVERBAL_EVENTS`에도 저장해 영상 타임라인에서 이동할 수 있게 연결했다.

### 3. 로컬 비언어 AI 연결
`backend/nonverbal_service.py`가 최상위 `nonverbal_ai/` 분석기를 실제 답변 업로드 흐름에서 호출한다.

현재 원칙:
- A!SK와 심층면접 모두 같은 답변 제출/전달분석 흐름 사용
- 최종 전달 안정성 점수는 아직 생성하지 않음
- 실제 음성의 침묵/음량 변화/속도 등을 측정
- 캘리브레이션 전 시선·자세는 `score_eligible=False`
- 캘리브레이션 전 시선·자세 이벤트는 사용자 타임라인에 저장하지 않음
- 실제 오디오 품질이 측정 불가이면 내용평가를 강행하지 않고 재녹화를 권장
- 영상 얼굴 분석이 실패해도 가능한 경우 오디오 품질 검사는 별도로 유지

### 4. RAG/언어 AI 결과 형식 정리
현재 질문 생성·답변 평가·최종 코칭의 핵심 필드는 이미 통일되어 있다.

- 질문: `question_type`, `question_text`, `question_reason`, `evaluation_points`, `rag_evidence`, `practice_reason`
- 답변 평가 DB 저장값: `scoring_version`, `job_evaluation`, `answer_evaluation`, `job_score`, `answer_score`, `strengths`, `improvements`
- 최종 코칭: `content_summary`, `delivery_summary`, `priority_focus`, `next_practice_goal`, `overall_score`

RAG가 계산하는 `answer_raw_score`, `answer_base_score`, `answer_excellence_bonus` 등 상세 계산값은 현재 DB에 저장하지 않는 값으로 통합 규격에 명확히 구분했다.
즉 현재 웹 리포트와 세션 코칭에 필요한 핵심 결과는 DB에 저장하고, 내부 검증용 세부 계산값은 RAG 런타임 결과로 유지한다.

### 5. 리포트
현재 리포트에서 구분한다.

- `내용 종합 점수`: 현재 `overall_score`의 정확한 의미
- `직무 핵심 반영도`
- `답변 구성 충실도`
- `전달 안정성`: 최종 기준 미확정이므로 점수 미표시
- 질문별 실제 전달 측정값
- 머뭇거림 표현 / 반복 표현 및 발생 시점
- 영상 타임라인

A!SK는 3개 질문을, 심층면접은 실제로 생성된 첫 질문과 꼬리질문 전체를 리포트에 넘긴다.

`종합 점수`라는 표현은 전달 안정성까지 포함한 것으로 오해할 수 있어 현재는 `내용 종합 점수`로 표시한다.

## 오디오 재녹화 규칙

비언어 AI의 실제 음성 신호 검사에서 마이크 무음·심한 소음 등으로 측정이 어렵다고 판단되면:

1. 내용평가를 점수로 진행하지 않음
2. 프론트에서 재녹화 안내
3. 같은 질문을 다시 녹화 가능

측정 실패를 낮은 점수로 바꾸지 않는다.

## 현재 남은 핵심 작업

### 최우선: 웹 캘리브레이션 연결
확정된 V1 기준:
- A!SK와 심층면접 모두 공통 적용
- 시각 캘리브레이션 하드 게이트
- 화면 중앙 응시
- 얼굴 전체 + 양쪽 눈 + 양쪽 어깨
- 3초 연속 안정 유지
- 음성 환경 확인 고정 문장
- 통과 전 실제 질문 시작 불가

현재 Python 캘리브레이션 로직은 있으나 React/FastAPI 사용자 흐름에는 아직 연결되지 않았다.

### 캘리브레이션 이후
- 캘리브레이션 프로파일을 해당 세션의 모든 답변 분석에 재사용
- 시선 1초 이상 이탈 평가
- 자세 2초 이상 이탈 평가
- 질문별 결과 → 세션 평균
- 전달 안정성 최종 가중치/점수 구간 확정
- 최종 전달 코칭 문구 연결

### 로컬 실행 확인이 필요한 부분
코드는 GitHub `main`에 연결했지만 실제 PC 환경에서 아래는 아직 최종 실행 확인이 필요하다.
- 심층면접 첫 질문 → 꼬리질문 1~3 → 리포트 전체 완주
- OpenAI STT/RAG 호출
- MediaPipe/OpenCV/librosa 비언어 분석
- 녹화 파일 형식과 ffmpeg 변환

## 아직 하지 않을 것

이번 프로젝트 목표상 아래는 우선순위가 아니다.

- AWS 등 외부 서버 배포
- 대규모 동시접속 대응
- 상용 수준 로그인/인증
- 운영 모니터링 시스템

발표 전 최종 확인은 한 대의 PC에서 전체 흐름을 실제로 한 번 완주하는 방식으로 진행한다.
